# CA App — content packs

Question packs for the CA App study application. Each pack is a JSON file of
multiple-choice questions on the ICAI Standards on Auditing, with the citation
that settles each answer.

`release.json` names the current pack. The app reads it, compares the version
against the pack it already has, and downloads the new one only if it is newer.

Nothing here is executable. These files are data.
